        Import from Strava

        1. On strava.com in a browser, hover your name (top right) and open Settings.
        2. Go to My Account, click Get Started under "Download your account", then Request download.
        3. Strava emails you a link. It can take a few hours. Download the zip and unzip it.
        4. Pick the activities.csv file inside it, below. Keep Strava's language on English so the columns match.

        The file is read on your device. Nothing is uploaded. Runs you already imported are skipped, so importing again is safe. Strava does not label easy, long or threshold, so each run starts as Easy (under 15 km) or Long and Medium feel. Change them in the list.
